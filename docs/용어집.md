# 대대대 용어집

대학교끼리 클릭으로 점수를 겨루는 캠퍼스 대항전 **대대대**에서 쓰는 말을 정리한다. 기획·코드·문서·발표에서 같은 개념은 같은 이름으로 부른다.

**코드** 칸은 코드에서 실제로 쓰는 이름(클래스·필드·enum·테이블·Redis 키)이다. 비어 있으면 코드에 그 개념을 가리키는 이름이 따로 없다. **피할 말**은 같은 개념을 가리키지만 쓰지 않기로 한 말이다.

## 사람과 소속

| 용어 | 코드 | 설명 | 피할 말 |
|---|---|---|---|
| **회원** | `User` | 학교 이메일로 인증하고 가입한 대학생. 한 학교, 한 학과에 속한다. | 유저, 사용자, 플레이어 |
| **관리자** | `Role.ADMIN` | 회원 관리, 문의 답변, 로고 내리기, 부정행위 확인을 하는 운영자. | 어드민, 운영팀 |
| **비회원** |  | 가입하지 않은 방문자. 문의만 남길 수 있다. |  |
| **학교** | `University` | 대항전의 기본 단위가 되는 대학. 학교마다 허용하는 이메일 도메인이 정해져 있다. | 대학, 캠퍼스(캠퍼스는 아래의 성장 모습을 가리킨다) |
| **학과** | `Department` | 학교 안의 소속 단위. 학교 안에서 따로 순위를 매긴다. |  |
| **숨김 학교** | `hidden` | 운영용으로 만든 학교. 공격·지원은 받지만 순위·지도·검색에는 보이지 않는다. |  |
| **학교 이메일 도메인** | `UniDomain` | 그 학교 회원으로 가입할 수 있는 이메일 주소 뒷부분(예: `yonsei.ac.kr`). |  |
| **회원 상태** | `UserStatus` | 회원이 서비스를 쓸 수 있는지를 나타내는 값. 정상, 정지(기간 제한), 차단(영구 제한), 탈퇴가 있다. |  |

## 점수

| 용어 | 코드 | 설명 | 피할 말 |
|---|---|---|---|
| **학교 점수** | `University.totalScore` | 학교에 쌓인 누적 점수. 학교 순위와 캠퍼스 성장 단계를 정한다. 공격을 받으면 줄어든다. |  |
| **학과 점수** | `Department.totalScore` | 학과에 쌓인 누적 점수. 학교 안의 학과 순위를 정한다. |  |
| **기여도** | `contribScore`, `totalContribScore` | 회원이 클릭과 지원으로 쌓은 개인 점수. 학교 안의 개인 순위를 정하고, 물약 구매와 클리커 업그레이드에 쓰는 재화도 된다. 쓰면 줄어든다. | 개인 점수, 포인트, 경험치 |
| **공격 점수** | `attackScore`, `totalAttackScore` | 회원이 공격으로 다른 학교에서 깎은 점수의 누적값. 기여도와 따로 센다. |  |
| **클릭 세기** | `clickPower` | 클릭 한 번이 만드는 기본 점수. 클리커 레벨이 정한다. | 클릭 파워, 공격력 |
| **기본 점수** | `base` | 한 번의 요청에서 나오는 점수의 바탕. 클릭 수에 클릭 세기를 곱한 값이다. 클릭·공격·지원 점수가 모두 여기서 출발한다. |  |
| **배율** | `multiplier` | 물약이 기본 점수에 곱하는 값. 효과가 남아 있는 동안만 적용된다. |  |
| **도서관 보너스** | `libraryBonus` | 회원이 자기 학교 중앙도서관 근처(100m 안)에서 클릭할 때 받는 추가 점수. |  |

## 행동

| 용어 | 코드 | 설명 | 피할 말 |
|---|---|---|---|
| **클릭** | `click` | 우리 학교를 위해 버튼을 누르는 기본 행동. 학교 점수, 학과 점수, 기여도가 함께 오른다. |  |
| **공격** | `attack` | 다른 학교의 학교 점수를 깎는 행동. 기본 점수의 30%만큼 깎고, 상대가 라이벌 학교면 33%를 깎는다. 우리 학교나 연합 학교는 공격할 수 없다. 상대 점수보다 많이 깎을 수는 없다. |  |
| **지원** | `assist` | 같은 연합 학교의 점수를 올려 주는 행동. 대상 학교는 기본 점수의 30%를 받고, 지원한 회원은 기여도를 얻는다. 우리 학교·학과 점수는 오르지 않는다. | 어시스트, 도움 |
| **피해량** | `damage` | 공격 한 번으로 실제로 깎인 점수. 상대 학교 점수가 모자라면 요청한 양보다 적다. | 데미지 |
| **라이벌 학교** | `rival` | 서로 맞수로 정해 둔 학교 묶음(예: 연세대학교·고려대학교). 라이벌 학교를 공격하면 더 많이 깎는다. |  |

## 순위와 캠퍼스

| 용어 | 코드 | 설명 | 피할 말 |
|---|---|---|---|
| **순위** | `rank` | 학교, 학과, 개인별 점수 줄 세우기. 학교 순위는 학교 점수, 학과 순위는 학과 점수, 개인 순위는 기여도로 정한다. | 랭킹(화면 문구는 예외) |
| **순위 변동** | `rankChange` | 오늘 순위와 그날 자정(한국 시간) 순위의 차이. | 어제 순위 대비 |
| **캠퍼스** | `campus` | 학교 점수에 따라 자라는 학교의 모습. 풀밭과 텐트에서 시작해 트윈 시계탑과 대축제까지 10단계로 커진다. |  |
| **캠퍼스 단계** | `CAMPUS_STAGES` | 캠퍼스가 지금 몇 번째 모습인지. 학교 점수가 단계마다 정한 기준을 넘으면 다음 단계로 올라간다. | 캠퍼스 레벨 |
| **지도** | `UniversityMapService` | 상위 학교들의 위치와 점수를 보여 주는 화면. |  |

## 연합과 대결

| 용어 | 코드 | 설명 | 피할 말 |
|---|---|---|---|
| **연합** | `Alliance` | 두 학교가 맺는 동맹. 만들 때 정한 시간(6~72시간)이 지나면 만료된다. 같은 연합 학교끼리는 공격할 수 없고 지원할 수 있다. | 동맹, 길드, 팀 |
| **연합 가입 신청** | `AllianceUniversity` | 학교가 연합에 들어가겠다고 요청하는 것. 대기, 승인, 거절, 탈퇴 상태를 거친다. |  |
| **연합 초대** |  | 기존 연합이 어느 연합에도 속하지 않은 학교에 보내는 가입 제안. 초대받은 학교가 승인하면 해당 연합에 가입한다. | 연합 권유 |
| **연합 상태** | `AllianceStatus` | 활성, 대결 중, 만료가 있다. |  |
| **연합 점수** | `ALLIANCE_SCORE` | 연합 학교들이 연합에 있는 동안 지원으로 보탠 점수의 학교별 합. |  |
| **대결** | `AllianceMatch` | 두 연합(각 2개 학교, 2:2)이 정한 시각에 붙는 승부. 신청, 예정, 진행 중, 종료, 취소 상태를 거친다. 두 연합이 만료되기 전에 끝나야 한다. | 매치, 전쟁, 연합전 |
| **A팀 / B팀** | `team`: `A`, `B` | 한 대결에서 두 연합을 가리키는 이름. |  |
| **대결 명단** |  | 대결이 시작될 때 고정한 네 학교. 시작한 뒤 연합 구성이 바뀌어도 대결은 이 명단으로 정산한다. |  |
| **대결 점수** | `MATCH_SCORE` | 대결 동안 A팀과 B팀이 각각 쌓은 점수. 더 높은 팀이 이긴다. |  |
| **대결 기여 점수** | `aUniversity1Contribution` 등 | 한 학교가 대결 점수에 보탠 몫. |  |
| **정산** | `AllianceMatchSettlement` | 대결이 끝난 뒤 진 팀의 점수를 이긴 팀에 옮기는 일. 진 팀 두 학교에서 각자의 대결 기여 점수만큼 학교 점수를 깎고(현재 점수까지만), 깎은 합을 이긴 팀 두 학교가 반씩 나눠 가진다. 비기면 아무 점수도 옮기지 않는다. | 보상 지급, 결산 |

## 성장과 상점

| 용어 | 코드 | 설명 | 피할 말 |
|---|---|---|---|
| **클리커** | `Clicker` | 클릭 세기를 정하는 회원의 도구. 1레벨에서 시작한다. |  |
| **클리커 레벨** | `clickerId` | 클리커의 단계. 레벨이 오를수록 클릭 세기가 커진다. |  |
| **클리커 업그레이드** | `ClickerUpgradeService` | 기여도를 내고 클리커 레벨을 하나 올리는 것. |  |
| **아이템** | `Item` | 상점에서 파는 물건. 물약과 로고 변경권이 있다. |  |
| **물약** | `ItemType.MULTIPLIER` | 기여도로 사는 기간제 아이템. 정해진 시간 동안 클릭 점수에 배율을 곱한다. | 포션, 버프 |
| **효과** | `ActiveEffect` | 지금 적용되고 있는 물약의 배율과 끝나는 시각. 새 물약을 사면 이전 효과를 덮는다. |  |
| **로고 변경권** | `LOGO_UNIVERSITY`, `LOGO_DEPARTMENT`, `LOGO_PROFILE` | 크레딧으로 사는 영구 아이템. 학교 로고, 학과 로고, 개인 로고 세 종류가 있다. | 커스텀 로고권 |
| **크레딧** | `CreditWallet`, `credit_balance` | 실제 돈으로 충전하는 재화(1원 = 1크레딧). 로고 변경권을 살 때 쓴다. 기여도와 섞어 쓰지 않는다. | 캐시, 코인, 포인트 |
| **충전** | `CreditHistoryType.CHARGE` | 토스페이먼츠 결제로 크레딧을 늘리는 것. 환불은 없다. |  |
| **구매 이력** | `UserItem` | 회원이 아이템을 산 기록. 구매 한 번이 한 건이다. |  |
| **크레딧 내역** | `CreditHistory` | 크레딧이 늘거나 줄 때마다 남기는 기록(충전·사용). |  |
| **구매 수단** | `PayType` | 아이템을 무엇으로 사는지. 기여도 또는 크레딧. |  |

## 인증과 부정행위 방지

| 용어 | 코드 | 설명 | 피할 말 |
|---|---|---|---|
| **학교 이메일 인증** | `EmailVerificationService` | 학교 이메일로 받은 6자리 코드를 입력해 그 학교 학생임을 확인하는 절차. |  |
| **가입 토큰** | `signupToken` | 이메일 인증을 마친 뒤 회원가입을 끝낼 때까지 쓰는 임시 증표(30분). |  |
| **로그인 세션** | `LoginSessionStore`, `sessionId` | 회원이 로그인한 기기. 한 계정에 한 기기만 로그인할 수 있다. |  |
| **로그인 잠금** | `AUTH_LOGIN_LOCK` | 비밀번호를 연달아 틀리면 잠시 로그인을 막는 것. |  |
| **요청 한도** | `ActionRateLimiter`, `ClickCountLimiter` | 회원이 짧은 시간에 보낼 수 있는 요청·클릭 수의 상한. 넘으면 거절하고 부정행위로 센다. |  |
| **부정행위** | `abuse` | 요청 한도를 넘는 등 매크로로 의심되는 행동. 관리자는 회원별 부정행위 횟수 순위를 본다. | 어뷰징, 핵 |
| **봇 확인** | `AbuseVerificationService`, `turnstile` | 부정행위로 클릭이 막힌 회원이 사람임을 증명해 다시 클릭할 수 있게 하는 절차(Cloudflare Turnstile). | 캡차 |
| **제출 ID** | `submissionId` | 클릭·공격·지원 요청마다 붙이는 고유 값. 같은 요청이 두 번 반영되지 않게 한다. |  |
| **멱등 키** | `idempotencyKey` | 구매 요청마다 붙이는 고유 값(`Idempotency-Key`). 같은 구매가 두 번 결제되지 않게 한다. |  |
